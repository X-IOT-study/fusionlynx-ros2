# Project Overview

FusionLynx is a thesis-oriented ROS 2 workspace for a MotionCore mecanum
robot. It integrates MotionCore hardware, wheel odometry, FAST-LIO,
wheel/LIO fixed-lag fusion, RTAB-Map mapping, evaluation, and thesis assets.

Start with:

1. `AGENTS.md` for stable workspace rules.
2. `docs/architecture.md` for system ownership and interfaces.
3. `docs/tf.md` for transforms and sensor extrinsics.
4. `docs/fusion.md` for state estimation.
5. `docs/slam.md` for FAST-LIO and RTAB-Map.
6. `docs/deployment.md` for build and runtime operations.
7. `docs/development.md` and `docs/development/git_workflow.md` for workflow.
8. `src/fusionlynx/AGENTS.md` for package-local rules.
9. `docs/AGENTS.full.md` for the complete pre-split rule archive.
